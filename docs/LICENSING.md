# UIAI Engine Licensing

UIAI Engine is commercially valuable infrastructure and the proof browser for Focusa-powered agents. The repository is licensed under the [Business Source License 1.1](../LICENSE) with a commercial licensing path.

This page is an operational summary, not legal advice. The `LICENSE` file controls.

## Why this repo has an explicit license

A public GitHub repository is visible and forkable under GitHub's platform terms, but visibility is not the same as permission to use, modify, distribute, or create derivatives. GitHub's licensing docs state that a repository needs a license for others to be free to use, change, and distribute the software.

UIAI Engine should not be left unlicensed. An explicit license protects the project while making the allowed evaluation and non-commercial paths clear.

## License model

UIAI Engine uses:

- **Business Source License 1.1 (BSL):** source-available license for the repository.
- **Additional Use Grant:** permits personal, educational, research, evaluation, demonstration, and other non-commercial use.
- **Founders Forge included access:** Founders Forge participants and portfolio projects may use UIAI Engine for their own internal product development and evaluation while participating in Founders Forge.
- **Commercial license:** required for commercial production, hosted/SaaS, resale, paid service, commercial browser automation, commercial agent infrastructure, or paid product-feature use outside the BSL terms.
- **Change License:** Apache License 2.0 on the Change Date stated in `LICENSE`, or earlier if required by the BSL terms for a specific version.

## What the BSL allows by default

BSL 1.1 grants rights to copy, modify, create derivative works, redistribute, and make non-production use of the Licensed Work. The license also allows an Additional Use Grant for limited production use.

For UIAI Engine, the Additional Use Grant covers personal/evaluation/non-commercial use and Founders Forge included access as described in `LICENSE`.

## What requires a commercial license

A separate commercial license is required for use outside the BSL and Additional Use Grant, including:

- running UIAI Engine as part of a paid product or paid product feature;
- offering UIAI Engine, modified UIAI Engine, or UIAI-powered browser/session/diagnostics functionality as a hosted service, managed service, API service, or SaaS;
- resale, sublicensing, paid distribution, or commercial agent/browser automation services;
- commercial production use that is not covered by the Additional Use Grant;
- removing or obscuring license notices.

## What is allowed without a commercial license

Subject to the `LICENSE` terms, the following are allowed:

- personal experiments and local development;
- educational and research use;
- evaluation, demos, proof-of-concept work, and non-production testing;
- non-commercial use;
- Founders Forge participant/portfolio internal product development and evaluation while participating in Founders Forge.

## Open source status

UIAI Engine is source-available under BSL 1.1. It is not open source until the Change License takes effect for a version.
